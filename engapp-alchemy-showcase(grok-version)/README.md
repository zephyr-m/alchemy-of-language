# EngApp · алхимическая UI-система

Интерактивный обзор визуального языка будущего тренажёра: цвета, типографика,
кнопки, стадии обучения, задания, прогресс, гильдия и награды.

```bash
npm run dev
```

На текущем ноутбуке зависимости уже подключены из существующего Vue-проекта,
поэтому повторная установка не нужна. После переноса проекта отдельно: `npm install`.

Проверка производственной сборки: `npm run build`.
